About this prototype

Construction AI prototype • conceptual 3D workspace and review markers

What works

Multiple locally stored JPG/PNG sheets, coordinate-scaled review markers, zoom/pan, review decisions, construction records, local browser saving, JSON export/import, and a conceptual 3D workspace gated by floor-plan and elevation uploads.

What is not connected yet

Fully bundled text recognition assets for guaranteed offline first-run use, the live Python text recognition engine, complete historical 42-candidate dataset, automatic cross-sheet interpretation, drawing-derived 3D geometry and clash detection, automatic drawing processing, cloud sync, and cross-device persistence. No measurements are automatically accepted as construction facts.
