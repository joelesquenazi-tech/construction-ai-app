What works

Multiple locally stored JPG/PNG sheets, coordinate-scaled review markers, zoom/pan, review decisions, construction records, local browser saving, JSON export/import.

What is not connected yet

The live Python OCR engine, complete historical 42-candidate dataset, automatic cross-sheet interpretation, 3D geometry, automatic drawing processing, cloud sync, and cross-device persistence. No measurements are automatically accepted as construction facts.
